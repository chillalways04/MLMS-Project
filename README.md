# ระบบบริหารจัดการและออกใบรับรองดิจิทัลอัตโนมัติพร้อมการตรวจสอบสิทธิ์ผ่านคิวอาร์โค้ด
### (Automated Digital Certificate Management and Issuance System with QR Code Verification)

เว็บแอปพลิเคชันเพื่อใช้ในการประมวลผลเกณฑ์คะแนน ออกใบรับรองดิจิทัลอัตโนมัติ และตรวจสอบสิทธิ์การปฏิบัติงานหน้างานผ่านรหัสคิวอาร์ เพื่อทดแทนขั้นตอนการจัดทำและตรวจสอบเอกสารด้วยมือ (Manual Process) ในโรงงานอุตสาหกรรม

## 📖 ภาพรวมของระบบ (Overview)
ในกระบวนการทำงานของโรงงานอุตสาหกรรม การจัดการเอกสารรับรองทักษะและความปลอดภัยของพนักงานมักเป็นกระบวนการทำมือ (Manual Process) ซึ่งใช้เวลานานในการรวบรวมคะแนน พิมพ์เอกสาร และแจกจ่าย รวมถึงมีความเสี่ยงต่อการปลอมแปลงเอกสารและตรวจสอบย้อนหลังได้ยาก

ระบบนี้ถูกพัฒนาขึ้นเพื่อ:
1. **ประมวลผลคะแนนอัตโนมัติ:** ตรวจสอบผลการฝึกอบรมจากฐานข้อมูลและตัดสินเกณฑ์การผ่านรับรองอัตโนมัติ (เกณฑ์คะแนน ≥ 80%)[cite: 1]
2. **ออกใบรับรองดิจิทัลพร้อม QR Code:** สร้างเอกสาร PDF และกำหนดรหัสความปลอดภัยสากล (UUID) ทันทีที่ผ่านเกณฑ์[cite: 1]
3. **ตรวจสอบสิทธิ์หน้างานแบบ Real-time:** เปิดให้ผู้ตรวจสอบสามารถสแกน QR Code ตรวจสอบความถูกต้องได้โดยไม่ต้องเข้าสู่ระบบ[cite: 1]
4. **มอนิเตอร์ความพร้อมของทีม:** ให้หัวหน้างานสามารถติดตามสถิติและสถานะทักษะของพนักงานตามสายการผลิตได้แบบเรียลไทม์

## 👥 กลุ่มผู้ใช้งานหลัก (Target Users)
ระบบจำแนกสิทธิ์การใช้งานออกเป็น 3 กลุ่มหลักตามบทบาทหน้าที่[cite: 1]:

1. **พนักงาน (Operator):** ตรวจสอบสถานะการฝึกอบรมของตนเอง และดาวน์โหลดใบรับรองดิจิทัล (PDF) เมื่อผ่านเกณฑ์[cite: 1]
2. **หัวหน้างาน (Supervisor):** ดูแดชบอร์ดสถิติ ติดตามผล และดูรายชื่อพนักงานตามโครงสร้างองค์กร (LINE, Section, Team) เฉพาะขอบเขตที่รับผิดชอบ[cite: 1]
3. **ผู้ตรวจสอบหน้างาน (Auditor / Safety Inspector):** สแกน QR Code บนใบรับรองเพื่อเปิดหน้าเว็บตรวจสอบความถูกต้องได้ทันทีโดยไม่ต้องเข้าสู่ระบบ[cite: 1]

<p align="center">
  <img src="docs/screenshots/01_login.png" width="600" alt="Login Page">
</p>

* **Frontend Route:** `/login`
* **Security:** รับข้อมูลและส่งตรวจสอบผ่าน RESTful API เพื่อออก Bearer Token สำหรับ Session

---

### 2. แดชบอร์ดตรวจสอบผลการอบรมของพนักงาน (Operator Dashboard)
ศูนย์รวมข้อมูลทักษะของพนักงาน แสดงอัตราความสำเร็จของหลักสูตร (Completion Rate)[cite: 2] และจำแนกวิชาที่ผ่านเกณฑ์และวิชาที่ต้องสอบซ่อมอย่างชัดเจน[cite: 2]

<p align="center">
  <img src="docs/screenshots/02_operator_dashboard.png" width="850" alt="Operator Dashboard">
</p>

* **สถิติภาพรวม:** แสดงจำนวนหลักสูตรทั้งหมด, ผ่านเกณฑ์แล้ว (≥ 80%), กำลังเรียน, และไม่ผ่าน (< 80%)[cite: 2]
* **การคำนวณความคืบหน้า (75%):** คำนวณจากสัดส่วนวิชาที่ผ่านเกณฑ์ (3 ใน 4 หลักสูตร)[cite: 2]
* **Action Items:** วิชาที่ผ่านเกณฑ์จะแสดงปุ่มสีเขียว **"ผ่านการทดสอบ"** ส่วนวิชาที่คะแนนไม่ถึงเกณฑ์จะแยกไปอยู่ในการ์ดเตือนสีแดงพร้อมปุ่ม **"ซ่อม"**[cite: 2]

---

### 3. การแจ้งเตือนผลผ่านเกณฑ์ (Passed Modal Dialog)
เมื่อพนักงานกดปุ่ม "ผ่านการทดสอบ" ระบบจะแสดง Modal ยืนยันผลคะแนน พร้อมปุ่มเปิดดูใบรับรองดิจิทัล[cite: 2, 7]

<p align="center">
  <img src="docs/screenshots/03_passed_modal.png" width="550" alt="Passed Modal Dialog">
</p>

* **User Action:** พนักงานคลิกปุ่ม **"View PDF (ใบประกาศ)"** เพื่อส่งคำขอให้ระบบออกใบรับรอง[cite: 7]
* **Backend Trigger:** ตรวจสอบสิทธิ์ผู้ใช้งานและดึงข้อมูลใบเซอร์แบบ Idempotent Transaction เพื่อป้องกันการออกเอกสารซ้ำซ้อน

### 4. ใบรับรองดิจิทัลพร้อม QR Code (Digital Certificate PDF)
เอกสารรับรองมาตรฐานที่สร้างขึ้นแบบไดนามิก ฝังรหัสความปลอดภัยสากล (UUID) และ Dynamic QR Code สำหรับตรวจสอบความถูกต้องหน้างาน[cite: 1, 3]

<p align="center">
  <img src="docs/screenshots/04_digital_certificate.png" width="800" alt="Digital Certificate PDF">
</p>

* **Dynamic Fields:** แสดงชื่อ-นามสกุล, รหัสพนักงาน, ชื่อหลักสูตร, วันที่ออกเอกสาร, และรหัสประจำใบรับรอง[cite: 3]
* **Dynamic QR Code:** ฝัง URL สาธารณะที่เชื่อมต่อกับรหัส UUID ประจำเอกสาร[cite: 1, 3]
* **Export Tool:** รองรับการดาวน์โหลดเป็นเอกสาร PDF สำหรับเก็บเป็นหลักฐานการทำงาน[cite: 1, 3]

### 5. แดชบอร์ดมอนิเตอร์และคัดกรองตามผังองค์กร (Supervisor Dashboard)
หน้าจอสำหรับหัวหน้างานเพื่อติดตามความพร้อมของลูกทีมในสายการผลิต คัดกรองข้อมูลตามผังองค์กร และวิเคราะห์ความเสี่ยง[cite: 1, 6]

* **Hierarchical Org Filter:** เมนูคัดกรอง 3 ระดับ `LINE` → `Section` → `Team` พร้อมระบบจำกัดสิทธิ์เฉพาะสายงานที่รับผิดชอบ[cite: 1, 6]
* **Donut Chart & KPI Cards:** สรุปสัดส่วนสถานะการเรียนรู้ (ครบถ้วน, ใกล้ครบ, กำลังดำเนินการ, ยังไม่เริ่ม) และคะแนนเฉลี่ยรวมของทีม[cite: 6]
* **Member Management:** ตารางรายชื่อลูกทีมรายบุคคล แสดงความคืบหน้า (%) และปุ่ม **"🔑 รีเซ็ตรหัส"** สำหรับแก้ไขปัญหาหน้างาน[cite: 6]

## 🛠 เทคโนโลยีที่ใช้พัฒนา (Tech Stack)

### **Front-end**
* **React.js & JavaScript (ES6+):** พัฒนา UI แบบ Single Page Application (SPA)[cite: 1]
* **CSS3 / Responsive Design:** ออกแบบรองรับการใช้งานทั้งบนคอมพิวเตอร์และอุปกรณ์เคลื่อนที่[cite: 1]

### **Back-end**
* **Node.js & Express.js:** สถาปัตยกรรม RESTful API ในการประมวลผลตรรกะระบบและการเชื่อมต่อข้อมูล[cite: 1]
* **JSON Web Token (JWT):** บริหารจัดการ Session และการควบคุมสิทธิ์ตามบทบาท (RBAC)

### **Database & Networking**
* **SQLite:** ฐานข้อมูลเชิงสัมพันธ์สำหรับจัดเก็บผังองค์กร, ข้อมูลผู้ใช้, คะแนนอบรม และรหัส UUID ของใบเซอร์[cite: 1]
* **Cloudflare Tunnel:** โซลูชันเครือข่ายความปลอดภัยสำหรับ Public Verification Endpoint ให้สามารถสแกนจากอินเทอร์เน็ตภายนอกได้[cite: 8]

## 🔒 สถาปัตยกรรมความปลอดภัย (Security Architecture)
* **Role-Based Access Control (RBAC):** แยกสิทธิ์เด็ดขาดระหว่าง Operator และ Supervisor[cite: 1]
* **BOLA / IDOR Prevention:** บังคับตรวจสอบ Token ใน Middleware ทุกครั้งเพื่อป้องกันการเรียกดูข้อมูลข้ามบัญชีพนักงาน
* **Anti-Tampering Design:** ตัว QR Code ไม่ได้เก็บข้อความตรงๆ แต่เป็น URL ชี้ไปยังรหัส UUID ในฐานข้อมูล ทำให้การปลอมแปลงบนเอกสารกระดาษไม่สามารถผ่านการตรวจสอบได้[cite: 1, 4, 8]
