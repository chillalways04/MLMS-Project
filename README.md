# ระบบบริหารจัดการและออกใบรับรองดิจิทัลอัตโนมัติพร้อมการตรวจสอบสิทธิ์ผ่านคิวอาร์โค้ด
### (Automated Digital Certificate Management and Issuance System with QR Code Verification)

เว็บแอปพลิเคชันเพื่อใช้ในการประมวลผลเกณฑ์คะแนน ออกใบรับรองดิจิทัลอัตโนมัติ และตรวจสอบสิทธิ์การปฏิบัติงานหน้างานผ่านรหัสคิวอาร์ เพื่อทดแทนขั้นตอนการจัดทำและตรวจสอบเอกสารด้วยมือ (Manual Process) ในสายการผลิตและโรงงานอุตสาหกรรม

## 📖 ภาพรวมของระบบ (Overview)
ในกระบวนการทำงานของโรงงานอุตสาหกรรม การจัดการเอกสารรับรองทักษะและความปลอดภัยของพนักงานมักเป็นกระบวนการทำมือ (Manual Process)[cite: 5] ซึ่งใช้เวลานานในการรวบรวมคะแนน พิมพ์เอกสาร และแจกจ่าย รวมถึงมีความเสี่ยงต่อการปลอมแปลงเอกสารและตรวจสอบย้อนหลังได้ยาก

ระบบนี้จึงถูกพัฒนาขึ้นเพื่อ:
1. **ประมวลผลคะแนนอัตโนมัติ:** ตรวจสอบผลการฝึกอบรมจากฐานข้อมูลและตัดสินเกณฑ์การผ่านรับรองอัตโนมัติ[cite: 5]
2. **ออกใบรับรองดิจิทัลพร้อม QR Code:** สร้างเอกสาร PDF และกำหนดรหัสความปลอดภัยสากล (UUID) ทันทีที่ผ่านเกณฑ์[cite: 5]
3. **ตรวจสอบสิทธิ์หน้างานแบบ Real-time:** เปิดให้ผู้ตรวจสอบสามารถสแกน QR Code ตรวจสอบความถูกต้องได้โดยไม่ต้องเข้าสู่ระบบ[cite: 5]
4. **มอนิเตอร์ความพร้อมของทีม:** ให้หัวหน้างานสามารถติดตามสถิติและสถานะทักษะของพนักงานตามสายการผลิตได้แบบเรียลไทม์[cite: 5, 9]

## 👥 กลุ่มผู้ใช้งานหลัก (Target Users)
ระบบจำแนกสิทธิ์การใช้งานออกเป็น 3 กลุ่มหลักตามบทบาทหน้าที่[cite: 5]:

1. **พนักงาน (Operator):** 
   - เข้าสู่ระบบเพื่อตรวจสอบสถานะผลการฝึกอบรมและทักษะของตนเอง[cite: 5]
   - ดาวน์โหลดใบรับรองดิจิทัลในรูปแบบ PDF เมื่อผ่านเกณฑ์ที่กำหนด[cite: 5]
2. **หัวหน้างาน (Supervisor):** 
   - เข้าถึง Dashboard สถิติผลการฝึกอบรมและรายชื่อพนักงาน[cite: 5]
   - คัดกรองและดูข้อมูลตามโครงสร้างผังองค์กร ได้แก่ LINE, Section และ Team ภายในขอบเขตสายการผลิตที่ตนเองรับผิดชอบ[cite: 5]
   - มีฟังก์ชันจัดการรีเซ็ตรหัสผ่านเริ่มต้นให้กับพนักงานในทีม[cite: 9]
3. **ผู้ตรวจสอบหน้างาน (Auditor / Inspector):** 
   - สแกน QR Code บนใบรับรองเพื่อเปิดหน้าเว็บตรวจสอบความถูกต้องและความแท้จริงของเอกสารได้ทันที โดยไม่ต้องเข้าสู่ระบบ[cite: 5]

## ✨ ฟังก์ชันและคุณสมบัติเด่น (Key Features)

### 1. ระบบประเมินเกณฑ์การรับรองอัตโนมัติ (Automated Evaluation)
- ตรวจสอบคะแนนการฝึกอบรมจากฐานข้อมูล โดยกำหนดเกณฑ์คะแนนตั้งแต่ **ร้อยละ 80 ขึ้นไป (≥ 80%)** ถือว่าผ่านเกณฑ์การรับรอง[cite: 5]
- แสดงผลสถานะความคืบหน้า (Progress) และจำแนกรายการที่ผ่านเกณฑ์และต้องสอบซ่อมอย่างชัดเจน[cite: 6]

### 2. การออกใบรับรองดิจิทัลและรหัสสากล (Dynamic Certificate Issuance)
- สร้างใบรับรองรูปแบบ PDF สำหรับผู้ที่ผ่านเกณฑ์โดยอัตโนมัติ[cite: 5]
- กำหนดรหัสสากลที่ไม่ซ้ำกัน (**UUID**) ให้กับใบรับรองแต่ละใบ เพื่อใช้เป็น Primary Key อ้างอิงในฐานข้อมูล[cite: 5]
- สร้าง **Dynamic QR Code** ประจำใบรับรอง ฝัง URL ปลายทางสำหรับตรวจสอบความถูกต้องหน้างาน[cite: 5]
- ระบบป้องกันการออกใบรับรองซ้ำซ้อน (Idempotent Transaction)[cite: 13, 14]

### 3. แดชบอร์ดคัดกรองตามผังองค์กร (OrgFilter & Team Monitoring)
- แสดงสถิติภาพรวมผ่าน Donut Chart และแถบ KPI อัตราการเรียนจบ (Completion Rate) และคะแนนเฉลี่ย[cite: 9]
- ตัวกรองตามลำดับขั้น: `LINE` → `Section` → `Team`[cite: 5, 9]
- ระบบล็อกสิทธิ์ (Data Scope Isolation) ป้องกันการเข้าถึงข้อมูลข้ามสายการผลิต[cite: 5]

### 4. หน้าตรวจสอบสิทธิ์สาธารณะ (Public Verification Endpoint)
- ตรวจสอบความถูกต้องของใบรับรองแบบ Real-time จากรหัส UUID
- แจ้งเตือนข้อผิดพลาดทันทีหากพบว่าใบรับรองถูกแก้ไข ดัดแปลง หรือไม่มีอยู่ในฐานข้อมูล[cite: 11]

## 🛠 เทคโนโลยีที่ใช้พัฒนา (Tech Stack)

### **Front-end**
- **React.js & JavaScript:** พัฒนาส่วนต่อประสานผู้ใช้แบบ Single Page Application (SPA)[cite: 5]
- **CSS / Responsive Design:** ออกแบบให้รองรับการแสดงผลทั้งบนคอมพิวเตอร์และอุปกรณ์เคลื่อนที่ (Smartphones/Tablets)[cite: 5]

### **Back-end**
- **Node.js & Express.js:** พัฒนาสถาปัตยกรรม RESTful API ในการประมวลผลตรรกะระบบ การยืนยันตัวตน และการดึงข้อมูล[cite: 5]
- **JSON Web Token (JWT):** ใช้ในการจัดการ Session และควบคุมการเข้าถึงตามบทบาท (RBAC)[cite: 13, 14]

### **Database & Networking**
- **SQLite:** ฐานข้อมูลเชิงสัมพันธ์สำหรับจัดเก็บข้อมูลโครงสร้างองค์กร, บัญชีผู้ใช้งาน, ผลคะแนนการอบรม และบันทึกรหัสใบรับรองดิจิทัล (UUID)[cite: 5]
- **Cloudflare Tunnel:** ระบบเชื่อมต่อเครือข่ายความปลอดภัยสำหรับ Public Verification Endpoint ให้สามารถสแกนตรวจสิทธิ์จากภายนอกได้[cite: 11]

## 🔒 สถาปัตยกรรมความปลอดภัย (Security Architecture)

- **Authentication & RBAC:** ตรวจสอบสิทธิ์ผู้ใช้งานทุกครั้งผ่าน Middleware (`Bearer Token`) เพื่อแยกหน้าที่ระหว่าง Operator และ Supervisor[cite: 13, 14]
- **BOLA / IDOR Prevention:** บังคับตรวจสอบ `requireOwnUserId` เพื่อป้องกันไม่ให้พนักงานเรียกดูผลสอบหรือใบรับรองของผู้อื่นผ่านการดัดแปลง Request[cite: 13, 14]
- **Anti-Tampering Verification:** ไม่เก็บข้อมูลตัวบุคคลไว้ใน QR Code โดยตรง แต่ใช้รหัส UUID อ้างอิงกับฐานข้อมูล เพื่อป้องกันการปลอมแปลงเอกสาร[cite: 5, 8, 11]
